# Sicherheitsrichtlinie

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern über
[GitHub Private Vulnerability Reporting](../../security/advisories/new).

Wir bestätigen den Eingang innerhalb von 7 Tagen und informieren über die Behebung.
Das Sicherheitskonzept ist in [arc42 Kapitel 8.5](docs/architecture/08-querschnittliche-konzepte.md#85-sicherheitskonzept-nach-owasp-top-10-2021) beschrieben.
