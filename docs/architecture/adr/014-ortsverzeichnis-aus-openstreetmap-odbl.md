# ADR 014: Ortsverzeichnis aus OpenStreetMap (ODbL)

- **Status:** angenommen
- **Kontext:** siehe [arc42 Kap. 9](../09-architekturentscheidungen.md) und die verlinkten Kapitel

## Entscheidung

Ortsverzeichnis aus OpenStreetMap (ODbL).

## Begründung

Alle Thüringer Orte und Ortsteile mit Koordinaten und amtlichem Kreisschlüssel; frei nutzbar mit Namensnennung

## Verworfene Alternativen

Amtliches Gemeindeverzeichnis (enthält keine Ortsteile, keine Koordinaten)
