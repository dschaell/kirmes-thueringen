# ADR 017: Recherche-Assistent statt Instagram-Auslesen

- **Status:** angenommen
- **Kontext:** siehe [arc42 Kap. 9](../09-architekturentscheidungen.md) und die verlinkten Kapitel

## Entscheidung

Recherche-Assistent statt Instagram-Auslesen.

## Begründung

Automatisches Auslesen verstößt gegen die Nutzungsbedingungen von Instagram und scheitert technisch; Text einfügen → Formular vorausfüllen ist legal und schnell

## Verworfene Alternativen

Scraper, Instagram Graph API (nur Business-Konten sichtbar)
