# ADR 007: Semgrep statt CodeQL als SAST

- **Status:** angenommen
- **Kontext:** siehe [arc42 Kap. 9](../09-architekturentscheidungen.md) und die verlinkten Kapitel

## Entscheidung

Semgrep statt CodeQL als SAST.

## Begründung

Eigene, verständliche Regeln (pg-Injection, Schichtgrenzen) im Repo

## Verworfene Alternativen

Nur CodeQL (eigene Regeln aufwendiger)
