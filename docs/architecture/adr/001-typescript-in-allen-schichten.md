# ADR 001: TypeScript in allen Schichten

- **Status:** angenommen
- **Kontext:** siehe [arc42 Kap. 9](../09-architekturentscheidungen.md) und die verlinkten Kapitel

## Entscheidung

TypeScript in allen Schichten.

## Begründung

Eine Sprache, geteilte Typen, geringerer Einarbeitungsaufwand für Ehrenamtliche

## Verworfene Alternativen

Java/Spring (schwergewichtig), Python (zweite Sprache neben Frontend)
